# PROMPT FOR CREATING A CREATIVE AGENCY WEBSITE

You are a frontend development expert specialized in creating immersive and modern digital experiences. I want you to create a complete website for a creative agency called "MIMESIS" using React 18 with Vite as the bundler, Tailwind CSS for styling, and Framer Motion for all animations. The site must be entirely in English with an elegant dark mode design using a color palette dominated by deep black (#000000) as the main background, white (#ffffff) for primary text, and violet and pink accents in gradients and luminous effects. The overall aesthetic should be minimalist but impactful, using plenty of negative space, glassmorphism effects with semi-transparent backgrounds (bg-white/5, bg-white/10) and subtle borders (border-white/10, border-white/20), all complemented by subtle violet-pink-violet gradients for hovers and decorative elements. The site must include several pages accessible via a fixed header that changes appearance on scroll with a blur effect (backdrop-blur-2xl), each page having its own content but sharing the same global elements: an AnimatedBackground with animated violet/pink orbs floating in the background with infinite rotation and scale animations, a CustomCursor that replaces the default cursor and adapts when hovering over interactive elements, and an interactive Chatbot always accessible. The Home page (Hero) must be immersive with a main title that changes color dynamically based on the user's horizontal mouse position, accompanied by a luminous glow effect, a understated subtitle, and two main CTA buttons: "Start a Project" redirecting to the Services page and "View Portfolio" redirecting to the Studio page. The Services page must present the agency's different services (Brand Identity, Digital Experience, Motion Design, Art Direction) as elegant cards with animated icons, indicative prices, feature lists, and a pricing section with three plans (Starter, Professional, Enterprise) where the popular plan is highlighted, followed by a special offers section and a final CTA. The Studio page must combine the team presentation (with photos or generative avatars, names, roles, and detailed bios), the agency's values (Authenticity, Innovation, Excellence, Collaboration) illustrated by animated icons, and a portfolio showcase of 6 projects with images, categories, descriptions, and elegant hover effects, all concluding with a "Schedule a Meeting" section that opens a centered booking modal. The Contact page must be clean with contact information (email, phone, address), a complete form with validation (name, email, company, desired service, message), opening hours, and a FAQ section with interactive accordion, plus a "Schedule a Meeting" button in the Hero that opens the same booking modal. The reusable BookingModal must be perfectly centered on the screen with a blurred backdrop, include a four-step progress indicator (Date selection with a grid of the next 14 business days, Time selection with 8 proposed slots, Personal information form with validation, and a Confirmation screen with meeting summary), and smooth animations at each step using Framer Motion with scale, opacity, and position variants. All animations must be smooth with durations between 0.6 and 0.8 seconds and sophisticated easing functions (ease: [0.16, 1, 0.3, 1]), buttons must have subtle hover effects (scale 1.02-1.05) and cards must reveal additional information on hover. The site must be fully responsive with breakpoints for mobile, tablet, and desktop, using Tailwind classes like grid-cols-1 md:grid-cols-2 lg:grid-cols-3/4, px-8 md:px-16 lg:px-24, and text-5xl md:text-7xl lg:text-8xl. Create this complete website with all these elements by meticulously following this visual style and immersive user experience.
